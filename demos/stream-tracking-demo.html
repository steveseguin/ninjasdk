Stream tracking

Join a room and list every stream the SDK has seen, using getStreams(): its state, when it was first and last seen, and its peer UUID. Publish test streams and view them to watch the states change.

  1. Connect to the room below.
  2. Publish a canvas stream here, or open the share link in a second tab and publish there.
  3. Click View on a stream from the other tab. Its state goes from pending to connected and a preview appears.

Key SDK calls in this demo 
const vdo = new VDONinjaSDK({ room });
vdo.addEventListener('listing', refresh);            // room list arrives / changes
vdo.addEventListener('videoaddedtoroom', refresh);   // someone started publishing
vdo.addEventListener('track', (e) => {               // media from a stream we view
  const { streamID, streams, track } = e.detail;
  showPreview(streamID, streams[0] || new MediaStream([track]));
});
await vdo.connect();
await vdo.joinRoom({ room });

for (const s of vdo.getStreams()) {
  console.log(s.streamID, s.state, s.firstSeen, s.lastSeen, s.uuid);
}
await vdo.view(streamID);   // state: pending, then connected
vdo.stopViewing(streamID);
