Media quality

Publish your camera with a chosen codec, bitrate, and resolution, change them while live, and watch the result in a second tab. Codec selection works best in Chromium-based browsers.

  1. Start as Publisher in this tab and allow the camera and microphone.
  2. Open the second tab. It opens as Viewer with the same stream ID; click Start there.
  3. Change settings and click Apply, then watch the video stats on either side.

Key SDK calls in this demo 
// Publisher
const sdk = new VDONinjaSDK({ host: 'wss://wss.vdo.ninja' });
await sdk.connect();
await sdk.publish(camera, {
    streamID,
    media: {
        video: { codec: 'VP9', maxBitrate: 2500, resolution: '1280x720@30' },
        audio: { maxBitrate: 128 }
    }
});
// Later, while live:
await sdk.updatePublisherMedia({ media: { video: { maxBitrate: 800 } } });

// Viewer (second tab)
await sdk.connect();
await sdk.view(streamID, { audio: true, video: true });
const stats = await sdk.getStats(); // raw WebRTC stats per peer
