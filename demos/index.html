Tips for testing

Two tabs
Use a demo's Open second tab link. The room is in the URL, so both tabs join the same one.
Other devices
Copy the share link to a phone or another computer. Peers connect directly, so no server setup is needed.
Camera and microphone
Browsers only allow capture on HTTPS or localhost.
Debugging
Open the browser console for detailed SDK connection logs.
